# Husayn Bijak

App belajar (PWA) untuk Husayn: **Membaca**, **Mengira**, **Menulis** (dengan semakan tulisan untuk M-Pencil) dan **Iqra' 1–3**.
Reka bentuk "Hutan Kertas": hutan hujan Malaysia daripada kertas potong, dengan 4 sahabat (Gajah Borneo, Orang utan, Kenyalang, Penyu).
Semua suara dirakam oleh Ayah.

- Buka: https://abbasismail2101.github.io/husayn-bijak/
- Pasang sebagai app: menu Chrome → **Install app / Add to Home screen**. Selepas dibuka sekali, app boleh digunakan tanpa internet.

Struktur: `index.html`, `app.js`, `app.css`, `sw.js` (cache offline), `audio/` (331 klip suara + `voice.json`), `img/`, `video/`, `fonts/`.
